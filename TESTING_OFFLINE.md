# Проверка сборки без квоты Gemini

## 1. Запуск

```bash
npm install
npm run dev:local
```

Откройте `http://localhost:3000`. В диагностике модель анализа должна отображаться как `local-deterministic`.

## 2. Приёмочные сценарии

Откройте «Симулятор» и проверьте:

| Сценарий | Ожидаемое поведение |
|---|---|
| 10. «Больше не звоните» | Карточка уважительно закрывает контакт; вопросов и продажи нет |
| 11. «За рулём, завтра в 11» | Фиксируется точный возврат, текущая продажа прекращается |
| 12. Прямой вопрос | Сначала ответ/способ проверки, а не новый SPIN-вопрос |
| 22. Гарантированная доходность | Claim Risk Guard заменяет гарантию прогнозом с источником |
| 23. «Займу две минуты» | В состоянии появляется контракт на 120 секунд; на 80% — предупреждение |
| 24. Исследовательский режим | Нет искусственной срочности; предлагается сравнение |
| 25. Повторное сопротивление | После второй просьбы опрос прекращается |
| 26. Двойной вопрос + «Да» | Copilot просит уточнить один параметр, не сохраняет два факта |
| 27. Недостоверная справка | Комплаенс-стоп и официальный путь проверки |
| 28. Неполная встреча | Запрашиваются недостающие параметры контракта встречи |
| 29. Отказ от апартаментов | Ветка «апартаменты» закрывается и сохраняется в handoff |

## 3. Устойчивость карточки

Запустите сценарий 22, затем 20 («Угу, понятно»). Высокоприоритетная карточка не должна исчезнуть или замениться устаревшей подсказкой. Во время реплики Андрея текущая карточка заморожена; свежая карточка появляется после окончания речи.

## 4. Итог звонка

Завершите тестовый звонок. Итог формируется без Gemini и содержит:

- подтверждённые факты без superseded-версий;
- согласованный шаг;
- блок «Контекст для следующего контакта»;
- границы, отвергнутые ветки, риски и открытые вопросы.

## 5. Автотесты

```bash
npm run lint
npm test
npm run build
```

Живое STT не является частью offline-приёмки: для него всё ещё нужны доступный Gemini Live, ключ и квота.

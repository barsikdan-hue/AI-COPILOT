# AI Copilot 4.0.2-rc.5

# AI Copilot риелтора — ANDREI OS 4

Copilot для звонков по недвижимости с устойчивым локальным ядром. Правила безопасности, границы клиента, факты, приоритеты и жизненный цикл одной карточки работают без Gemini. Модель используется как дополнительный семантический слой, когда доступна.

## Быстрый запуск без квоты Gemini

```bash
npm install
npm run dev:local
```

Откройте `http://localhost:3000`, нажмите «Симулятор» и запускайте готовые сценарии. Для Windows можно запустить `START_OFFLINE_TEST.bat`, для macOS/Linux — `./start-offline-test.sh`.

Важно: локально работают симулятор, анализ, факты, подсказки и итоги. Живое распознавание микрофона/звука звонка пока использует Gemini Live и требует ключ и квоту.

Подробная приёмка: [TESTING_OFFLINE.md](TESTING_OFFLINE.md).

## Режимы анализа

- `COPILOT_ANALYSIS_MODE=auto` — детерминированные P0-события локально, остальные реплики через Gemini с автоматическим локальным fallback.
- `COPILOT_ANALYSIS_MODE=local` — полностью локальный анализ; ключ не требуется.
- `COPILOT_ANALYSIS_MODE=gemini` — Gemini для обычной семантики, но безопасность и границы всё равно остаются детерминированными.

Скопируйте `.env.example` в `.env` при необходимости. Ключ хранится только на сервере и не попадает во frontend.

## Что входит в OS 4

- P0-приоритет: комплаенс → stop/time → риск обещаний → прямой вопрос/коррекция → встреча → SPIN.
- Fact Ledger с источником, цитатой, статусом и `supersedesFactId` для исправлений.
- Одна стабильная карточка: TTL, приоритет, защита от устаревших ответов и semantic anti-repeat.
- Исследовательский режим, повторное мягкое сопротивление и запрет повторять отвергнутую ветку.
- Контракт времени с предупреждением на 80% и проверка качества согласия на встречу.
- Session handoff: активные факты, границы, риски, запрещённые ветки и открытые вопросы.
- Маскирование телефона, email, паспорта, карты и СНИЛС перед LLM-запросом.
- AudioWorklet для PCM16/resampling и ограниченная очередь WebSocket вместо мгновенного сброса аудио.

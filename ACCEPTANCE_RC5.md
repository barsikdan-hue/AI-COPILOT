# AI Copilot 4.0.2-rc.5 — Semantic Core / Objection Flow

Дата: 2026-09-23

## Что исправлено

- Единый semantic evidence layer для критериев, опыта выбора, доступности капитала, взрослых детей и классификации вопросов доверия.
- «Важные критерии» закрываются по смыслу ответа клиента, включая несколько критериев из одной реплики.
- «Опыт выбора / покупки» засчитывает работу с агентом, подборки, просмотры и изучение рынка.
- «Первоначальный взнос» / доступность средств закрывается ответами «деньги на руках», «свои средства», «ничего продавать не планирую» в корректном контексте.
- Семейная ипотека закрывается как `not_applicable` при совершеннолетних детях; упоминание семьи больше не создаёт ложного ЛПР.
- Бюджет сохраняет базовый ориентир и stretch-диапазон: 30 млн -> 35–40 млн при сильном варианте.
- Отказ от ипотеки закрывает ППИ как `not_applicable` до явного возврата клиента к ипотеке.
- ППВ синхронизирован с каноническим контрактом встречи: позднее согласие снимает старое сопротивление и закрывает ППВ во всех слоях.
- Активные возражения получили контекстную отработку; добавлено отдельное возражение «рынок может снизиться» и сравнение с депозитом.
- Кнопка «Отработка возражений» использует последнее незакрытое возражение, а не статическую фразу.
- Карточки возражений раскрываются и показывают цитату клиента, готовую реплику и цель отработки.
- SPIN-кнопки формируют вопрос из контекста, а не повторяют четыре фиксированных текста.
- «Доверие» считает семантически разные технические и личные вопросы и не увеличивает счётчик за перефразированный дубль одной темы.
- Liveness: содержательная финальная реплика клиента не оставляет пустой суфлёр; старое незакрытое возражение при этом не навязывается автоматически на каждую следующую фактическую реплику.

- взрослые дети -> семейная ипотека `not_applicable`;
- ложный ЛПР из «с семьёй?» отсутствует;
- бюджет: `Ориентир 30 млн руб; до 35-40 млн руб при сильном варианте`;
- критерии: подтверждены локация, сдача, ликвидность, цена, инфраструктура, доходность;

- средства на руках / первый платёж: `confirmed`;

- сравнение «не меньше депозита» получает отработку доходности.
